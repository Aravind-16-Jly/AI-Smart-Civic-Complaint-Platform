# CivicMind AI

A polished full-stack demo for an AI-powered citizen complaint and urban intelligence platform.

## Project structure

- `frontend/` — React + Vite + Tailwind UI
- `backend/` — Express API with demo endpoints

## Run locally

### Frontend

```bash
cd frontend
npm install
npm run dev
```

### Backend

```bash
cd backend
npm install
npm run dev
```

## Notes

This initial release includes a production-style landing page, auth demo, citizen dashboard, authority dashboard, and a map view.
